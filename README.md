This project is feature-locked, meaning it will not recieve any new features from what it has now. The project will still be updated to new Minecraft versions.
# Transformable Items
Lets you move and resize held items, with the additional option of disabling Item Height Animations(Held item moving up and down when switching items or attacking)
## Installation
1. Install your mod loader of choice
2. Download the mod for your Minecraft version and mod loader of choice
3. Move it into your `.minecraft/mods` directory.
4. Launch the game
## Configuration
You can open the user-friendly custom made configuration by either opening it via Mod Menu(or the built in mod list when using Forge) or using the keybind(F7 by default, configured in Controls)
